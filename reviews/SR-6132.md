## Verdict

## Findings

| ID      | Severity | Summary | Refs |
| ------- | -------- | ------- | ---- |
| FND-001 | high | The required row fields omit `expired`, which the contract agreed with ix-board (SWM-261) lists beside `state` and the ticket asks for. State the field and its rule (for example whether it stays true for an order acted after `AckExpired`, and what it is for an open order past its deadline). | spec/functional/FR-071-order-ack-deadline-and-timeout.md:85-91 |
| FND-002 | medium | `oldest_available_at` is required to be the oldest time with complete data, but the section says nothing about senders that predate the index, so the statement cannot hold during a rolling upgrade. The code returns the session queue key (`session/<machine>/<session>`), the receipt event target. Name that value so two implementers cannot read it differently. | spec/functional/FR-071-order-ack-deadline-and-timeout.md:85-86 |
